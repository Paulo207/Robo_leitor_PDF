# Pasta de Entrada de PDFs

Coloque aqui os arquivos PDF das faturas COELBA que deseja processar.

Os PDFs serão automaticamente:
- Detectados (se monitoramento estiver ativo)
- Processados
- Movidos para 'processados' ou 'erros' após processamento

## Formatos Suportados
- PDFs com texto nativo
- PDFs escaneados (via OCR)
